GOOD TO KNOW

Clear answers.
No surprises.

Understand what the platform can do—and where Discord’s boundaries still apply.

Can Sentinel stop every raid or nuke?

No. It can detect and respond to supported signals, but no Discord bot can guarantee prevention of every action. Audit-log timing, permissions, rate limits, and the actor’s authority affect outcomes.

Who can see my server’s logs?

The dashboard API checks that the signed-in Discord user is the actual owner of the selected server and that Sentinel is installed there. Keep your Discord account secure and review OAuth access.

What does a backup restore?

Supported structural data such as roles, channels, categories, and permission overwrites. It does not restore message history, attachments, integrations, webhooks, invites, or member role assignments.

Will High security ever flag a legitimate member?

Yes, aggressive thresholds can create false positives. Start with Medium, tune the thresholds, and test High in a private server before using it in a live community.

Why are public statistics sometimes unavailable?

Statistics depend on the bot process, Discord gateway cache, and database. When the API is unavailable, the page should show a temporary unavailable state rather than inventing numbers.

Does installing Sentinel replace Discord permissions?

No. Sentinel can only perform actions allowed by its granted permissions and role position. Configure least-privilege access and keep human administrator accounts protected.
